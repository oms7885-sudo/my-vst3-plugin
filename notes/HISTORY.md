# 작업 기록 (요약)

시간 순서. 숫자의 출처와 버린 시도를 남겨 둔다.

1. Bass-To-MIDI 플러그인(`main`)에서 출발. 사용자가 "DI 자체 변조"로 신스 플러그인을 새로 만들기로 함.
2. 피치 트래킹 하이브리드, Lock 방식을 시도했으나 지연과 소리 때문에 롤백. 이후 여러 번 "계속 이 방식으로" 확정.
3. Model D 패널 구성: 오실레이터 3개, 믹서, 필터, 컨투어, Mod, Osc 3 Control, Decay, Keyboard Control.
   Overload 노브, Sub Detect 등 무그에 없는 것은 삭제. 파라미터 표 + UI 분담 문서 작성.
4. 트리거: 합성 테스트는 실제와 달랐다. 주석 달린 실제 녹음으로 보니 주기 길이의 레벨 창이 2배음에 잠겨
   헛트리거 553개 → 28 ms 고정 창으로 해결. 위상 점프/음정 변화 단서는 순이득이 없어 쓰지 않음.
5. 컨투어 오버슈트 1.22, 연타 누적 최대 1.60 (AJH MiniMod 자료: 평소 0–8 V, 재트리거 시 10.5 V; 서스테인 최대 약 80 %).
   낮은 컷오프에서 레조넌스 페이드.
6. 2026-11-10 "모두 적용": 기본음 추적, Emphasis 눈금, 믹서 드라이브 1/3.4, 범위 수정, 출력단.
   - 시제품은 위상이 도는 속도로 기본음을 찾았는데(공개 녹음에서 음정 맞음 52 %), 배음이 더 큰 음과 잔향에서 실패.
     → 주기(YIN) 방식으로 교체, 위상 지연 보정, 잔향 구분 추가.
   - 사용자 녹음의 옥타브 패턴(52→104 Hz)에서 앞 음의 잔향을 따라가는 문제를 발견해 "피킹으로 커졌는가" 검사 추가.
     "앞 음과 같은 음이면 인정" 규칙은 옥타브 패턴에서 오작동해서 기본 꺼짐(`ftAgain`).
7. 같은 날: 다이얼 눈금(dial0/dial1/timeDial), Amount of Contour 10 = 4옥타브, 값 칸에 Cutoff 주파수 병기.
8. External Source(DI/Feedback), Gate → Trig Thresh, 새 프리셋 4개, 플러그인 이름 mOog.
9. 2026-11-11: 사용자가 실제 무그 영상과 비교해 "오실레이터가 덜 단단하고 디스토션 입자가 곱다"고 함.
   → 관성 시제품(비교 음원 0/0.5/0.8/1.0) → 최대 고정으로 빌드. 믹서 곡선 B/C(비대칭)는 근거가 없어 A(tanh) 유지.
   Monark도 들어봤는데 과하고 전자음 같다고 함. 그래도 기준으로 쓰기로 함.
10. 이 대화에 컴퓨터를 "연결"하는 방식으로는 명령 실행이 안 됐다(파일 주고받기와 화면 조작만).
    그래서 Code 탭의 Local 세션으로 옮겨 Monark를 직접 재기로 함.

## 도구 (`notes/tools/`)

대화 중 임시 폴더에서 쓰던 것을 옮겨 둔 것이라 **경로가 예전 임시 폴더로 적혀 있다. 쓰기 전에 고칠 것.**

- `render.cpp`: 엔진에 float32 모노 파일을 넣어 렌더 (`key=value`로 내부 값 지정).
- `osc_dump.cpp`: 오실레이터 위상, 추적 컷오프, 찾은 기본음, 트리거를 샘플마다 덤프.
- `tracker_trace.cpp`: 추적기의 판단을 ms 단위로 출력 (`#define private public`으로 내부를 읽음).
- `pitch_metric.py`: 사용자 녹음에서 YIN 기준 음정 대비 오실레이터 음정이 맞는 비율.
- `saw_shape_metric.py`, `util.py`: 이상적 톱니 대비 배음 편차.

사용자 DI 녹음은 저장소에 없다(공개 저장소라 올리지 않음). 작업 폴더에 따로 받아서 쓸 것.
